Микросервис на FastAPI для автономной обработки, рерайтинга и форматирования новостных текстов с использованием API
GigaChat.

## 📖 О проекте

Этот сервис является частью микросервисной архитектуры городского новостного портала. Его задача — принимать "сырой"
текст новости от парсера и возвращать качественно переработанный контент под разные нужды (сайт, соцсети, SEO,
официальные сводки) без участия человека.

**Контекст архитектуры:**

1. **Symfony 7** — основной сайт (витрина новостей, объявлений, статей).
2. **Go** — высокопроизводительный парсер внешних источников.
3. **Python (этот репозиторий)** — AI-сервис для обогащения и форматирования контента. *(Взаимодействие между сервисами
   осуществляется через Apache Kafka).*

## ⚡ Возможности

Сервис поддерживает несколько режимов обработки через строгие системные промпты (`StrEnum`), что исключает
"галлюцинации" нейросети и гарантирует сохранение фактов:

| Режим (`mode`)  | Описание                                                                           |
|:----------------|:-----------------------------------------------------------------------------------|
| `rewriteStrong` | Строгий рерайт с жестким запретом на добавление новых фактов или изменение смысла. |
| `rewrite`       | Классический живой рерайт с сохранением всех цифр, имен и цитат.                   |
| `summary`       | Сжатие текста до 3–5 предложений (кто, что, где, когда, почему).                   |
| `social`        | Форматирование в пост для соцсетей (2–4 абзаца, эмодзи, хештеги).                  |
| `seo`           | SEO-оптимизация: цепляющий заголовок, лид-абзац, подзаголовки, списки.             |
| `official`      | Перевод в официально-деловой стиль (нейтрально, структурно).                       |
| `custom`        | Выполнение произвольной инструкции пользователя.                                   |

## 🛠 Технологический стек

- **Язык:** Python 3.12+
- **Фреймворк:** FastAPI, Uvicorn (async)
- **Управление зависимостями:** `uv` (молниеносный менеджер пакетов)
- **Валидация:** Pydantic V2, `StrEnum`
- **HTTP-клиент:** `httpx` (асинхронный, с автоматическим обновлением токенов)
- **Логирование:** `loguru` (структурированные логи с ротацией)
- **Инфраструктура:** Docker, Docker Compose, Hot-reload для разработки
