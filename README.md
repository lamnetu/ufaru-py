# GigaChat News Service

Микросервис на FastAPI для автономной переработки новостных текстов через GigaChat API.

## Архитектура

Часть системы городского портала (3 микросервиса):

- **Symfony 7** — сайт (новости, статьи, объявления)
- **Go** — парсер источников
- **Python (этот репо)** — сервис переписывания через GigaChat

Связь между сервисами — Kafka.

## Возможности

Сервис принимает сырой текст новости и возвращает переработанный в одном из режимов:

| Режим           | Описание                                  |
|-----------------|-------------------------------------------|
| `rewriteStrong` | Строгий рерайт с запретом на галлюцинации |
| `rewrite`       | Живой рерайт с сохранением фактов         |
| `summary`       | Сжатие до 3–5 предложений                 |
| `social`        | Пост для соцсетей с эмодзи и хештегами    |
| `seo`           | SEO-статья с заголовками и списками       |
| `official`      | Официально-деловой стиль                  |
| `custom`        | Пользовательский промпт                   |
